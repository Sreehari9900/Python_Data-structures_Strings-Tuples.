This repository contains solutions to Python Assignment 1, covering fundamental operations on **strings** and **tuples** — two of Python's core built-in data types.

---

## ![overview](https://img.shields.io/badge/-📋_Overview-informational?style=flat-square)

The assignment is split into two parts:

1. **Strings** – concatenation, slicing, indexing, and built-in string methods
2. **Tuples** – creation, concatenation, repetition, and element access

## ![strings](https://img.shields.io/badge/-🧵_Part_1:_Strings-orange?style=flat-square)

### 1. String Concatenation
- Takes user input for a name and concatenates it with `"Hello "`
- Appends a welcome message to the result

### 2. String Slicing and Indexing
- Extracts the first and last characters
- Slices the first 5 and last 11 characters
- Reverses the string
- Extracts a specific substring (`"Python"`) using slicing

### 3. String Methods
- Converts a sentence to uppercase and lowercase
- Uses `.capitalize()` to restore the original casing
- Counts occurrences of the character `'t'`
- Replaces `"Python"` with `"Machine Learning"` using `.replace()`

## ![tuples](https://img.shields.io/badge/-🔢_Part_2:_Tuples-purple?style=flat-square)

Using `tuple1 = (10, 20, 30)` and `tuple2 = (40, 50, 60)`:

- Concatenates both tuples into `t_combine`
- Repeats the elements of `t_combine` three times
- Accesses the 3rd element
- Retrieves the first three elements
- Retrieves the last three elements
